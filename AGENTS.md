# Developer & Agent Guidelines (AGENTS.md)

## Core Repository Contract

1. **`patches/` is the FINAL VERIFIED OUTPUT only:**
   - The files under `patches/` represent published, immutable production artifacts for downstream consumers (e.g. via direct `curl`).
   - `patches/` must **NEVER** be read as the source input to generate or validate a candidate production patch.

2. **Authoritative Generation, Validation, and Promotion Pipeline (`v2.pipeline`):**
   Every patch (Patch 11 and Patch 51) must follow this strict unidirectional pipeline:
   ```
   Authoritative Upstream Inputs
     │
     ▼
   Deterministic V2 Generation
     │
     ▼
   Candidate Artifact (`candidate_patches/<patch-id>/<patch-filename>`)
     │
     ▼
   Exact Validation against Bound Target Source Tree
     (Strict Gate: 0 offsets, 0 fuzz, 0 rejects, valid syntax, deterministic postimage)
     │
     ▼
   Deterministic Regeneration Equality Verification
     (Two independent generation passes must yield byte-identical content)
     │
     ▼
   Promotion to Stable `patches/` Path
     │
     ▼
   Regenerate Metadata & Manifest (`patches/manifest.json`, `BASELINE.json`)
     │
     ▼
   Verify Committed Public Artifact == Validated Candidate (Byte-for-byte)
   ```

3. **Fail-Closed Rule:**
   - If candidate generation or validation fails at any point, the public `patches/` directory is **never modified**.

4. **Single-Pass Application:**
   - `exact_patch` (or `v2.pipeline`) performs the single validated real application on a clean target tree.
   - Never validate a patch by applying it to the tree and then invoke a second `patch -p1` or second validation step on the same tree.

5. **Canonical Target Lineages & Boundaries:**
   - **GKI 6.12:** Public Patch 51 is strictly `patches/gki-android16-6.12/51_deinlined_susfs_hooks_android16-6.12-2025-09_r38.patch` (bound to `android16-6.12-2025-09_r38`).
   - **Historical Commit `c8909f7`:** Preserved for provenance/internal lineage records only; it is NOT a second public Patch 51.
   - **Midori Sources:** Reference-only trackers in upstream watcher; never authoritative input.
   - **Kernel Compilation:** Strictly out of scope; belongs downstream. No kernel build artifacts in this repo.
   - **No Hand-Editing:** All patches in `patches/` must be generated by code, never hand-edited.
